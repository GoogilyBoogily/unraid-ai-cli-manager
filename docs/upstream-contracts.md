# Upstream contracts

Inspected on 2026-11-11. These source observations don't establish behavior on Unraid 7.3.4. Record actual server evidence in `server-validation.md` before approving vendor targets or public releases.

- [Unraid events](https://raw.githubusercontent.com/unraid/webgui/master/sbin/emhttp_event) run synchronously. The manager's mount hook must only enqueue work. The stop hooks enforce admission and bounded draining.
- [Plugin Manager](https://raw.githubusercontent.com/unraid/webgui/master/emhttp/plugins/dynamix.plugin.manager/scripts/plugin) registers a plugin before running post-hooks. Post-hooks receive type, method, plugin basename, and an empty error on success. SHA256 is supported in FILE entries.
- [Cron registration](https://raw.githubusercontent.com/unraid/webgui/master/sbin/update_cron) includes cron files only for registered plugin basenames. Keep the plugin basename `ai-cli-manager.plg` aligned with its configuration directory.
- [UserScripts schedule writer](https://raw.githubusercontent.com/Squidly271/user.scripts/master/source/user.scripts/usr/local/emhttp/plugins/user.scripts/exec.php) writes both schedule copies. Its records are keyed by full wrapper script path and contain script/frequency/id/custom. [The page](https://raw.githubusercontent.com/Squidly271/user.scripts/master/source/user.scripts/usr/local/emhttp/plugins/user.scripts/Userscripts.page) uses disabled/start/stop/custom frequency values. Unknown schemas and unknown legacy source bytes must stop takeover.
- [Claude installer](https://claude.ai/install.sh) accepts a version argument and performs vendor package verification. The inspected installer SHA256 was `3a68d3406cf674e17bed1733a4dcf37805e2e47d87417700007d7e1aa766a944`. It bootstraps through a downloaded Claude installer binary, so the manager validates the requested installed version afterward. [DISABLE_AUTOUPDATER](https://code.claude.com/docs/en/setup) preserves manual updates.
- [Codex installer](https://chatgpt.com/codex/install.sh) accepts `--release VERSION` and `CODEX_NON_INTERACTIVE=1`. The inspected SHA256 was `44ac252c1b9a68c02bdf0de8e1c6cbfde36fc1afa8684624962eae7d4c461e70`. Run it in a private candidate HOME so vendor pruning never reaches live packages. Preserve its integrity checks.
- The existing desktop's public Codex package metadata reports layoutVersion 1, version 0.167.1, entrypoint bin/codex, resourcesDir codex-resources, pathDir codex-path, and execServer bin/codex-exec-server. Required Linux helpers include codex-path/rg, codex-resources/bwrap, and bin/codex-code-mode-host. No credentials or other private home contents were read or copied for this observation.
- [Codex configuration reference](https://learn.chatgpt.com/docs/config-file/config-reference) describes startup update checks and managed in-app update requirements. Daemon updater suppression must be checked separately on the supported host. Writing configuration alone isn't proof of OFF behavior.
